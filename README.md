# talenco-assets

認証の外に置く必要がある小さな公開アセットの置き場。

| ファイル | 用途 |
|---|---|
| `jieikan-map-screen.jpg` | 陸自駐屯地マップ（GAS）の画面キャプチャ。Canva の表紙（タレンコラボ「陸自駐屯地マップ」）に取り込むための公開URL。公開情報のみで、クライアント名は含まない |
| `talenco-tasks-favicon.png` | 社内タスク管理アプリ「Talenco Tasks」（Google Apps Script）のファビコン。GAS の `setFaviconUrl` は公開URLしか受け付けないためここに置く。参照元: talenco-jp-inc/talenco-tasks |

機密情報・個人情報・クライアント名の入るものは置かない。
